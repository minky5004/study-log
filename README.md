# study-log

공부 세션 단위로 무엇을 · 얼마나 공부했는지 기록하고, 쌓인 기록을 통계로 보는 웹 애플리케이션.
마크다운 파일로 학습 노트를 쌓던 TIL 리포를 대체한다.

> **현재 상태: 설계 완료 · 구현 시작 전.**
> 아래는 만들려는 것이고, 아직 동작하는 기능은 없다.
> 진행에 따라 이 문서를 실제 구현 범위로 갱신한다.

## 무엇을 푸는가

마크다운 파일은 쓰기 편하지만 두 가지를 못 한다.

- **검색** — IDE 에서 grep 하면 찾아지지만, 분야·기간·태그를 조합해 좁힐 수는 없다
- **집계** — 얼마나 꾸준히 했는지, 어느 분야에 치우쳐 있는지 파일 목록으로는 알 수 없다

DB 로 옮겨 검색과 통계를 얻되, **마크다운으로 다시 내보내 옵시디언 vault 로 열 수 있게** 해서
원래 쓰던 방식을 잃지 않는 것이 목표다.

## 만들 것

| 영역 | 내용 |
|------|------|
| 기록 | 공부 세션 단위 CRUD — 제목 · 날짜 · 시작/종료 시각 · 분야 · 태그 · 요약 · 마크다운 노트 |
| 검색 | 제목 · 요약 · 노트 본문 키워드 + 분야 · 태그 · 기간 필터 |
| 통계 | 일별 잔디 히트맵 · 주간/월간 추이 · 분야별 도넛 · 시간대별 분포 |
| 입출력 | 전체 기록을 YAML 프론트매터 마크다운 ZIP 으로 내보내기 / 다시 가져오기 |
| 인증 | 조회 공개 · 쓰기는 단일 관리자 계정 |

## 기술 스택

Java 21 · Spring Boot 4.1 · Gradle · Spring Data JPA · Spring Security · Thymeleaf ·
PostgreSQL(운영) / H2(로컬) · commonmark-java + jsoup · Chart.js

서버 렌더링 단일 배포. 별도 프론트엔드 빌드를 두지 않는다.

## 로컬 실행

```bash
./gradlew bootRun
```

Java 21 이 필요하다. Gradle 은 래퍼를 쓰므로 따로 설치하지 않아도 된다.
